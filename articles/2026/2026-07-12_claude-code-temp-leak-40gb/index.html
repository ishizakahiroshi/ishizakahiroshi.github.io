失敗談 2026-07-12

Cドライブの空きが謎に減るので Claude Code に調べさせたら、犯人は Claude Code 自身だった

255GB の C ドライブ、空きが 50.5GB。定期的に一時ファイルは消しているのに、気づくとまた減っている。原因調査を Claude Code に任せたら、40 分後に「犯人は私です」という報告が返ってきました。%TEMP% に溜まっていたのは 33,966 個・37.8GB。5 日間の実測データ付きの調査ログです。

この記事のテーマ

Windows の C ドライブが「消しても減り続ける」とき、どう犯人を突き止めるかの実録です。名前パターンとサイズでのグループ化、タイムスタンプの日別集計、バイナリ内の文字列解析、実行中プロセスのロード中モジュール実測、という段階を踏んで、単一バイナリ配布の CLI ツールが起動のたびにネイティブモジュールを %TEMP% へ展開したまま後始末しない、という仕組みまで降りていきます。9 割超がたった 1 日（毎時約 2,900 個・11 時間）で生成されていた、という発見も含めて、一次データを多めに載せています。
