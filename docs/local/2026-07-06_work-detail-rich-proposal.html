なぜ作ったか

複数の AI コーディング CLI を並列で走らせると、どのセッションが承認待ちで止まっているか分からなくなります。ターミナルを行き来する時間が積み重なるのが不便でした。

AI を「使う側」で終わらず「業務に組み込む側」として、決定論的に動かす部分と AI に委ねる部分の境界を設計した実装です。

使い方（30 秒で起動）

# インストール
$ npm install -g many-ai-cli

# 起動（ブラウザが開く）
$ many-ai-cli
  1. 上のコマンドで起動すると、ローカルの管理ダッシュボードが立ち上がります。
  2. 走らせたい AI CLI を登録すると、各セッションがタイルで並びます。
  3. 承認待ちが出たら 1 タブでまとめて承認。スマホからでも同じ画面が開けます。
