従来：縦積み
1 枚が縦に大きく、10 枚で延々スクロール。下の About・記事に届く前に疲れる。

スクロール対策：3 案の比較

A. 横スワイプ推奨

  • 縦スクロール激減：作品欄は 1 画面に収まる
  • スマホ操作（横フリック）と相性が良い
  • CSS の scroll-snap だけ。JS ほぼ不要
  • 次カードが覗くので「もっとある」が直感的

B. 2 列コンパクト

  • スマホで 2 列＝縦が半分に
  • 一覧性は高いが 1 枚が小さく説明が削れる
  • 横スワイプほどの「見せ場」感は出ない

C. 最初 4 枚＋開く

  • 初期 4 枚だけ、タップで残りを展開
  • 記事欄と同じ「もっと見る」方式で統一感
  • ただし作品は一目で見せたい → やや消極的

おすすめは A（横スワイプ）＋ PC はグリッドのまま。同じ 1 つの HTML/CSS で、画面幅で出し分けます（@media でスマホだけ display:flex; scroll-snap に切替）。実装は app.js の renderWorks() に手を入れず CSS 中心で完結できます。

この案で進める場合の作業

  • ① 作品追加：docsweep / PlainSheet を WORKS に追加（フロント 9 枚化）。short/long 説明は README から生成。
  • ② 全作品ページ：残り 8 個（worklog-bridge, syncway, many-tab, tab-title-prefix, nextcloud-safe-html-viewer, manabi-map, ai-log-clean, claude-code-context-diet）を載せる works.html を新設。
  • ③ 10 枚目カード：renderWorks() に「もっと見る」カードを追加（既存の dl-stats CTA カードの隣 or 置換）。
  • ④ スマホ横スワイプ：#works-grid の CSS に @media(max-width:640px) の scroll-snap を追加。

フロント 9 枚に「どれを選ぶか」はお好みで差し替え可。上のモックは Star 数・完成度・見栄えで暫定選定しています（★11 の offline-md、★4 の many-ai-cli を上位に）。
